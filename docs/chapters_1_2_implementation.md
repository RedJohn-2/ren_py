## Система компаньона

Переменная `companion` (строка) отслеживает, кто из девушек с Леоном:

| Этап | Возможные значения | Откуда |
|------|-------------------|--------|
| Глава 1.1, выбор «выбежать» | `alice`, `mari`, `shinna` | Случайно |
| Глава 1.1, выбор «остаться» | `sylvia` | Фиксировано |
| Глава 1.2–1.4 | Из 1.1 | Переходит по `jump` |
| Глава 2.1, «подождать» | `mari`, `alice` | Случайно |
| Глава 2.1, «не терять время» | `helena`, `shinna`, `sylvia` | Случайно |
| Глава 2.2 | Из 2.1 | Переходит по `jump` |

Для показа и речи компаньона используются хелперы `c_show("emotion")` и `c_say("text")` (определены в `init python` блоке chapter_1_3_events.rpy / chapter_1_4_events.rpy).
